Автономное приложение формата All-in-One (AIO) для консоли PlayStation 4 (GoldHEN), объединяющее офлайн-каталог игр, фоновый BitTorrent-клиент (`storre_torrentd`) и прямой фоновый установщик пакетов `.pkg` (`storre_installerd`) в едином ТВ-интерфейсе 1080p под управление DualShock 4.

---

## 🎯 Назначение

* **Какую задачу решает:** Полный цикл поиска, скачивания по торрентам, прямой установки `.pkg` в систему и последующей P2P-раздачи на консоли PS4 без ПК и лишних переключений между отдельными утилитами.
* **Целевое оборудование и среда:** Sony PlayStation 4 (прошивки `5.05 – 14.02+` с GoldHEN и включённым BinLoader на порту `9090`), а также хост-сборка под Windows (`SDL2`) для отладки интерфейса.
* **Формат поставки:** Готовый установочный пакет Fake PKG (`IV0000-STOR00001_00-PS4STORRE0000000.pkg`) со встроенным каталогом и автономными ELF-демонами публикуется в разделе **Releases**. Исходная мастер-база и бинарный архив `catalog.pak` обрабатываются локально вне Git.

## ✨ Особенности

* **Консольный 10-foot UI (`1920×1080`, DualShock 4):** Пропорциональная типографика `Noto Sans`, сетка обложек `6×2`, встроенная экранная клавиатура `EN / RU` с живой фильтрацией, цветные подсказки кнопок геймпада и модальные подтверждения опасных действий (выход, удаление торрента или игры).
* **Офлайн-каталог и локальный пайплайн базы:** Автоматический парсинг ежемесячных дампов Rutracker (`.xml.xz`) без полной распаковки на диск (`tools/update_catalog.ps1`) и упаковка только релизов с активными торрент-хешами в облегчённый архив (`tools/pack_release_catalog.py`).
* **Изолированные фоновые демоны (FreeBSD / Orbis ELF):** Автозапуск `storre_torrentd` (порт `8788`, с Web UI для браузера) и `storre_installerd` (порт `8285`, прямая передача в системный `bgft`) через GoldHEN BinLoader без конфликта с другими Homebrew.
* **Защита HDD консоли (I/O Mutex):** Очередь закачек `max_parallel = 1` по умолчанию и автоматическая пауза активных торрентов на время распаковки/записи `.pkg` на внутренний диск.
* **Управляемый жизненный цикл P2P (Smart Seed & Clean):** После установки игра остаётся на фоновой раздаче до достижения `Ratio 2.0x` или `7 дней` (либо до ручного удаления), после чего временный `.pkg` очищается с диска.
